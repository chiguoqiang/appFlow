## 1. 核心想法

一款极简习惯打卡 App：用户创建想养成的习惯，每天一键打卡，通过连续天数与完成率可视化
激励自己坚持。目标是验证「AI 生产线」全流程，同时产出一件真实可用的工具。

## 2. 目标用户

| 用户群 | 描述 | 核心诉求 |
|--------|------|---------|
| 想养成习惯的个人用户 | 尝试建立运动/阅读/喝水等日常习惯的人 | 打卡要快（一键），进度要看得见（连续天数/完成率） |

## 3. 功能清单（MVP 范围）

| # | 功能 | 优先级 | 验收要点 |
|---|------|--------|---------|
| 1 | 习惯列表（今日视图） | P0 | 打开即见今日待打卡习惯；一键打卡，状态即时刷新 |
| 2 | 创建/编辑习惯 | P0 | 表单含名称、图标（预设集选择）、颜色（token 色板）、目标频率（每天/每周 N 次，N∈1-7）；可编辑可删除 |
| 3 | 习惯详情 + 统计 | P0 | 最近 30 天日历热力图、连续天数、总打卡数、完成率 |
| 4 | 本地持久化 | P0 | 杀进程重开数据不丢；单文件本地存储，无需网络 |
| 5 | 数据重置 | P1 | 设置页一键清空全部数据（带二次确认） |

## 4. 明确不做（Out of Scope）

- 账户注册/登录、云同步
- 提醒推送通知
- 补签/补打卡（只打当天）
- 社交功能（分享/好友/排行）
- 多语言（仅中文界面）
- 深色模式（P0 仅浅色，token 架构预留扩展）

## 5. 技术约束

| 约束项 | 值 |
|--------|-----|
| 平台 | Flutter（iOS 模拟器优先验证） |
| 最低系统版本 | iOS 13+ / Flutter stable 当前版 |
| 网络/后端 | 无网络依赖，纯本地存储 |
| 账户体系 | 无登录 |
| 其他硬约束 | 遵循 flutter-dev-playbook 规范体系（AGENTS.md 三级 Rules）；Riverpod 状态管理 |

## 6. 参考与偏好

- 风格参考：市面主流打卡类 App 的今日卡片式布局；视觉干净、留白充分
- 反感：开屏广告式复杂首页、层级过深（核心动作 ≤ 2 跳可达）
